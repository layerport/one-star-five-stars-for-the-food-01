## What it does

`main.py` (Python standard library only) writes a single sentence to
`/output/entry.txt`: a one-star review of planet Earth from an alien
tourist — baffled that humans greet strangers by shaking hands, which is
how they spread their plagues — who still admits the dumplings were so
good they would risk a second pandemic for one more plate.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: every run writes the same sentence.
